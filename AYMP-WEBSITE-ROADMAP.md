# AYMP Website — Structure & Stability Roadmap

## Goal
Keep the site simple, fast, useful, shareable and expandable without breaking existing working pages.

## Main visitor journey
Home → Discover → Play → Learn/Ask → Share → Return

## Primary sections
1. Home — clear introduction and strongest calls to action.
2. Game Zone — Runner, Snake, Daily Brain, Mystic 3D Quest.
3. Global Discovery — trending stories with timeout + fallback content.
4. Food Discovery — food, recipes and preparation explanations.
5. Ask AYMP — question/answer experience; AI backend to be added properly later.
6. Future Technology — continuously updated technology/science discovery.
7. AYMP / 999xyz999 utility display — informational only; no guaranteed value/profit claims.
8. Revenue — added only after visitor experience and retention are stable.

## Audit findings to address
- Home page contains repeated `Our Sacred Products` sections; consolidate only after checking all product links/assets.
- Home page currently mixes many different purposes; future cleanup should make the main journey obvious without deleting working features.
- Global Trending must never remain on a permanent loading state; live sources need hard timeouts and fallback content.
- Ask AYMP is currently a public-knowledge/Wikipedia search, not a general AI assistant.
- Game Zone should show only working games as primary cards; future games should be clearly marked as coming soon.

## Safety rule for future updates
Do not overwrite or delete a working page just to add a feature. Inspect the current file first, make the smallest change possible, then verify the resulting file exists on the main branch.

## Revenue principle
Build traffic, engagement, repeat visits and sharing first. Then introduce suitable monetization such as advertising, sponsorships and premium digital experiences without making the site confusing or misleading.
